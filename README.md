# 🌦️ Clima Guarizinho 2

Aplicação desenvolvida para consulta e monitoramento das condições meteorológicas em **Guarizinho** (Itapeva - SP).

## 📋 Sobre o Projeto

O **Clima Guarizinho 2** tem como objetivo fornecer informações climáticas atualizadas de forma rápida, simples e acessível, auxiliando no acompanhamento da previsão do tempo local.

## ✨ Funcionalidades

- Consulta da temperatura atual, mínima e máxima
- Previsão do tempo para os próximos dias
- Informações sobre umidade relativa do ar, velocidade do vento e probabilidade de chuva
- Interface responsiva e de fácil visualização
