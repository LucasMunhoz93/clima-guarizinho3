# 🌦️ Clima Guarizinho 2

Aplicação desenvolvida para consulta e monitoramento das condições ambientais em **Guarizinho** (Itapeva - SP)

## 📋 Sobre o Projeto

O **Clima Guarizinho 2** tem como objetivo fornecer informações climáticas atualizadas de forma rápida, simples e acessível, auxiliando no acompanhamento da previsão do tempo loca.

## ✨ Funcionalidades

- Consulta da temperatura atual, mínima e máxima.
- Previsão do tempo para os próximos dias.
- Informações sobre umidade relativa do ar, velocidade do vento e probabilidade de chuva.
- Interface responsiva e de fácil visualização.

## 🛠️ Tecnologias Utilizadas

- **Android** (`ClimaGuarizinho-Android-Pr...` no repositório).
- **Linguagem / Ambiente:** Kotlin / Java / Android Studio.
- **API de Clima:** OpenWeatherMap / WeatherAPI.
